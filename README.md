# Rajeev Yadav — Portfolio

Modern, 3D-styled personal portfolio website of **Rajeev Yadav**, Frontend Developer (Varanasi, UP, India).

> Single-file site — everything (HTML, CSS, JS) lives in `index.html`. No frameworks, no build step.

## ✨ Features

- **3D particle space** background with mouse parallax
- **3D tilt cards** — photo, education, skills, projects react to the pointer
- **Glassmorphism** navigation and cards
- **Animated gradient** headline + typing effect
- **Skill ticker**, cursor spotlight, glowing auras
- **Scroll-reveal** 3D entrance for every section
- Fully **responsive** (mobile hamburger menu)
- Respects **`prefers-reduced-motion`**

## 📑 Sections

Home · About · Experience · Education · Skills · Projects · Achievements · Contact

## 🛠 Tech

| Layer | Used |
| --- | --- |
| Markup | HTML5 |
| Styling | CSS3 (custom properties, grid, flexbox, backdrop-filter) |
| Logic | Vanilla JavaScript (ES6+, IntersectionObserver, Canvas 2D) |
| Fonts | Space Grotesk + Inter (Google Fonts) |

## ▶️ Run locally

Double-click `index.html`, or serve the folder:

```powershell
npx serve .
```
